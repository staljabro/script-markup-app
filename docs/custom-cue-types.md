# Custom cue types

Open **Tools → Manage Cue Types**.

## Available foundations

- **Cue Point Type**: based on SFX/Scene behaviour.
- **Note Type**: free-position text.
- **Block Type**: rectangular area.

Enter a name, choose an MDI toolbar icon, and optionally set a prefix and suffix. New Cue Point types use a default margin of 75.

After creation, the custom type appears in the toolbar and Options. Its full appearance can be configured like a built-in cue type. Prefix and suffix can be changed later in Options.

## Ordering

Drag custom cue-type rows in Manage Cue Types to change their toolbar order.

## Removing a type

Removing a custom type also removes every cue using it. The confirmation reports the number of affected cues. Download a backup before destructive changes when the project must be recoverable independently of Undo.

## Project storage

Names, icons, ordering, type foundation, affixes, appearance, visibility, locks, and cues are stored in `.cueproj` files.
