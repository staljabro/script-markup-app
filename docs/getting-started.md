# Getting started

## Start a new document

1. Select **Save / Load** in the top toolbar.
2. Select **Open PDF** and choose the source script.
3. Choose a cue tool from the second toolbar.
4. Click a page and enter the cue text.
5. Use **Options** to configure cue types and **Inspector** to change selected cues.

For multiline formatted text, choose **Text box** and click two opposite corners. Enter its content in the Inspector that opens, select text to format it, and drag the box's corner handles to resize it. See [Text boxes](cue-inspector.md#text-boxes).

Opening a new PDF clears the current cues, custom cue types, and cue-type changes, then restores the application defaults. Save the existing project first if it must be retained.

## Save your work

- **Save Project** downloads a timestamped `.cueproj` file.
- **Save Project As** lets supported browsers choose the filename and destination.
- Browser autosave maintains a recovery copy, but it is not a replacement for a downloaded project file.
- **Export PDF** creates a finished annotated PDF; it does not create an editable project.

The header indicates whether the project has unsaved changes and shows the latest autosave time.

## Reopen existing work

Use **Save / Load → Load Project** to open a `.cueproj`. The source PDF, cues, custom types, appearance settings, Prompt/Showcall layout, dividers, and headers are restored together.

## Recommended workflow

1. Import the PDF.
2. Configure cue types and custom types.
3. Add and review cues.
4. Download project backups at useful milestones.
5. Use the bulk tools only after reviewing their previews.
6. Export the final PDF.
