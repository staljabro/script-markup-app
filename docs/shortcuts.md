# Keyboard and pointer shortcuts

| Input | Action |
| --- | --- |
| Esc | Close the topmost dialog, tool, or drawer; then cancel pending geometry or clear selection |
| Delete / Backspace | Delete selected unlocked cues, divider, or header |
| Ctrl/Cmd + S | Save a timestamped project copy |
| Ctrl/Cmd + Z | Undo |
| Ctrl/Cmd + Shift + Z | Redo |
| Ctrl/Cmd + Y | Redo on Windows-style keyboards |
| Ctrl/Cmd + D | Duplicate selected unlocked cues |
| Arrow keys | Nudge selected cues by 1 unit |
| Shift + Arrow | Nudge by 10 units |
| Alt/Option + Arrow | Nudge by 0.25 units |
| Ctrl/Cmd + scroll | Zoom from 50% to 200% |
| Ctrl/Cmd-click | Toggle cues in a multiple selection |
| Shift-click in cue list | Select the visible range from the selection anchor |
| Ctrl/Cmd + Shift-click | Add a cue-list range to the current selection |
| Pointer drag on empty page space | Marquee-select intersecting visible cues |
| Double-click | Edit a cue, fade, block, or header label |
| S / 1 | Select SFX |
| T / 2 | Select Scene |
| D / 3 | Select DCA |
| N / 4 | Select Note |
| F / 5 | Select Fade |
| B / 6 | Select Block |

Keyboard shortcuts do not activate while typing in an input, select, or text area.
