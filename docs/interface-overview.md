# Interface overview

## Main toolbar

- **Save / Load** opens document and project controls.
- **Undo** and **Redo** restore recent editor snapshots.
- **Options** opens application and cue-type options.
- **Tools** opens bulk operations and cue-type management.
- **Help** opens the built-in quick guide.

The document title can be renamed from the header. The header also shows the application version and save status.

## Cue toolbar

- **View Cues** toggles the cue-list overlay.
- **Pointer** selects and manipulates existing cues.
- Visible built-in and custom cue types appear as tool buttons.
- Page controls navigate directly between pages.
- **Fit width**, **Fit page**, the scale slider, Ctrl/Cmd-scroll, and **100%** control zoom.
- **Inspector** opens the selected-cue properties drawer.

## Cue list

The cue list is an overlay and does not shift the document. It supports search, type filters, custom-property filtering, multiple selection, inline renaming, and selection actions. Drag its right edge to resize it.

## Options and Inspector drawer

Options and Inspector share one right-hand drawer. Switching between them changes its contents without closing and reopening it. Drag the drawer's left edge to resize it. Options accordions start collapsed each time the drawer opens.

## Canvas

Pages can be displayed in a line or side by side. Visible guide lines indicate cue-type margins. Dashed 50%-opacity cue lines are editing handles only and are excluded from exported PDFs.
